# UCFMS placeholder registry

Every dummy value Jake will replace with a real site value, and where it appears.
Swap them all at once, then run `python3 placeholders.py --check` in this folder. It lists anything still left.

## JCL and batch COBOL

Generated by `python3 placeholders.py --update`; rerun it after editing any job.
Most jobs set `HLQ` and `LOADLIB` once at the top (`// SET ...`), so those are one change per job.
