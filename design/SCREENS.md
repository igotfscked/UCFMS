# UCFMS screen mockups

Status: **draft for Jake's review**, 2026-10-14. Companion to [APP_DESIGN.md](APP_DESIGN.md). Generated by `mockups.py` in this folder; edit the screen bodies there and rerun it rather than editing this file.

Every screen is drawn at 3270 model 2 size (24 rows x 80 columns; the `+--+` border is outside the screen). Each screen has an ISPF panel and a CICS BMS map with the **same body**, so users see the same layout in both. Only the top two and bottom two rows differ:

| | ISPF panel | CICS map |
|---|---|---|
| Row 1 | panel ID, title, short message | transaction + map name, title, date |
| Row 2 | `Command ===>` / `Option ===>`, scroll amount on lists | `Selection ===>` (fast path, e.g. `=2`), user ID, time |
| Row 23 | long message | message line |
| Row 24 | F keys | PF keys; F3 is Back, F12 returns to the menu, CLEAR exits |

Conventions: `____` input field; `_` in the Cmd column is a line-command field. Data shown is invented.

## Screen flow

```
Main Menu (1)
 |-1-> Search Criteria (2) --Enter--> Results (3)
 |                                     |-D--> Record Detail (4)
 |                                     |-F5-> Basket (5)
 |                                     '-F6-> Basket (5)
 |                                     Basket choice 1 -> Claimant (8) -> Claim Detail (7)
 |                                     Basket choice 2 -> Claim Detail (7), basket added
 |-2-> Find Claims (6) --S--> Claim Detail (7)
 |                     --P--> Process Claim (9)
 |                     --F5-> New claim: go to Query (2) to fill a basket
 |                           Claim Detail: F4 -> Claimant (8), F6 -> Process Claim (9)
 |-3-> Reports (10) --S--> online result (11), or job submitted
 '-4-> Admin (12) --options 2, 3, 6--> Confirm Job (13)
F3 goes back one screen, F12 returns to the menu, =n jumps to module n.
```

Sounds like (3) uses Soundex, so JON, JOHN and JHON (J500) or MUHAMMAD and MOHAMMED (M530) match, on last name and, if entered, first name. Validation errors (non-numeric ZIP, unknown type, nothing indexed) put the cursor on the field.
